# オリジナルファイル形式について
ゲーム開発で、キャラクターの立ち絵をPSD形式で用意することがあります。
PSD形式はアルファチャンネルに対応しており、レイヤー情報を保持している画像形式のため、
一つのファイルで画像差分を管理することに優れています。

しかし、PSD形式はレイヤー情報を持ちますが、レイヤー同士の細かい関係や排他的なレイヤー表示の責務を待ちません。
これらの機能は、PSDを利用するアプリケーション側で実装することが可能ですが、そのファイル自体がそれらの情報を保持することはありません。

そのため、アプリケーションを跨いでそれらの情報を渡すことは難しいです。

## LIVF形式
そこで、私は「LIVF」というオリジナルのファイル形式を作ることにしました。  
LIVF形式は、PSD形式のようにレイヤー情報を保持することに加えて、レイヤー同士の関係性や排他的なレイヤー表示の責務を持つことができるファイル形式です。
ファイル自体はZIP形式で圧縮されており、内部にはJSON形式のメタデータとPNG形式の画像ファイルが格納されています。
